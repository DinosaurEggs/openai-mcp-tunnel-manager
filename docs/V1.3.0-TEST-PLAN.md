# v1.3.0 测试与验收

基线：Manager 1.2.0 / official tunnel-client v0.0.21。本文是验收流程，不是已通过的测试报告。所有自动及手工测试均须记录 commit、实际客户端版本、操作系统、架构、结果和失败证据。只使用独立测试配置、状态目录和专用测试 Tunnel；远程 CRUD 不操作生产数据。

## 自动化测试与构建

在 Windows PowerShell、仓库根目录执行（SDK 版本以 global.json 为准）：

```powershell
dotnet --info
dotnet restore tests/OpenAITunnelManager.Tests/OpenAITunnelManager.Tests.csproj
dotnet test tests/OpenAITunnelManager.Tests/OpenAITunnelManager.Tests.csproj -c Release --no-restore
if ($LASTEXITCODE -ne 0) { throw "Tests failed" }
foreach ($target in @(@{Platform="x64";Rid="win-x64"}, @{Platform="ARM64";Rid="win-arm64"})) {
    dotnet restore src/OpenAITunnelManager.App/OpenAITunnelManager.App.csproj -r $target.Rid
    if ($LASTEXITCODE -ne 0) { throw "Restore failed" }
    dotnet publish src/OpenAITunnelManager.App/OpenAITunnelManager.App.csproj -c Release -p:Platform=$($target.Platform) -r $target.Rid --self-contained true --no-restore -o artifacts/$($target.Rid)
    if ($LASTEXITCODE -ne 0) { throw "Publish failed" }
}
```

GitHub Actions 的 WinUI 3 build 工作流对 PR 运行源码约束检查、行为测试、x64/ARM64 Publish、发布文件检查及 x64 启动和单实例 smoke test。必须核对当前 HEAD 的运行结果，不使用历史成功记录替代本次验证。

## 发布门禁

所有本版本范围内的用例均需实际执行并通过，记录无法执行的原因。ARM64 在原生设备运行 smoke test；仅交叉 Publish 不代表通过实机测试。真实远程认证用例缺少测试凭据时标记未执行。不得在草稿 PR 未完成、CI 未通过或发布验收未完成时发布 v1.3.0。

当前分支为开发中的部分实现。版本号和正式发布保持不变，待全部目标实现并完成验证后再更新。
